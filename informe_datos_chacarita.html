Veredicto

Es más viable de lo que parecía en la charla anterior — y por una razón concreta: la pieza que se asumía más difícil de conseguir gratis, estadísticas de partido con xG (expected goals), ya existe gratis para la Primera Nacional, con historial completo desde la temporada 2009/10. No hace falta pagar Wyscout para tener ese nivel de detalle en un primer sistema.

Lo que sí es cierto es que ninguna de estas fuentes gratuitas tiene un contrato que autorice su uso: son APIs no documentadas o scraping, en zona gris legal. Son perfectamente razonables para un proyecto de análisis interno o un prototipo — no para un producto que se vaya a vender o publicar puertas afuera sin más trabajo (ver Encuadre legal).

El hallazgo principal: Sofascore

Sofascore no publica una API pública, pero el sitio se alimenta de una API REST propia (api.sofascore.com) que responde en JSON sin necesidad de credenciales. Se buscó el ID interno de Chacarita, se confirmó que la Primera Nacional está mapeada como torneo 703, y se descargaron datos reales: plantel, calendario y estadísticas partido a partido.

La letra chica técnica

La API bloquea la librería estándar de Python (requests) con error 403 — detecta la huella TLS del cliente, no el User-Agent. curl pasa sin problema, y en Python se resolvió con curl_cffi (imita la huella de Chrome). Es una protección liviana, pero confirma que no es una API pensada para consumo externo: puede endurecerse en cualquier momento.

Transfermarkt en la práctica

A diferencia de Sofascore, Transfermarkt no tiene bloqueo de huella TLS: una petición HTTP simple con un User-Agent de navegador devuelve la página completa sin fricción técnica. Se ubicó el club correcto (el ID que suele circular de memoria — 2093 — pertenece a un club amateur alemán; el de Chacarita es otro) y se extrajeron 34 perfiles de jugadores con un solo request.

La diferencia con Sofascore no es técnica, es contractual: los Términos de Servicio de Transfermarkt prohíben explícitamente el acceso mediante bots o "screen scraping", y además restringen usar su contenido para entrenar sistemas de IA/ML. Que el sitio no lo bloquee técnicamente no significa que esté permitido — es la fuente con la brecha más grande entre "se puede" y "está autorizado".

Qué corregir de la charla anterior

Honestidad primero
  • "Goal-API" no existe como producto bajo ese nombre. Es probable que sea una confusión con Goalserve (un proveedor real, pero cuya cobertura de Primera Nacional no se pudo confirmar) o directamente con API-Football.
  • FutPythonTrader es real, pero su cobertura de Argentina no estaba confirmada — la charla anterior lo dio por hecho sin evidencia. El catálogo público no expone qué ligas incluye sin crear una cuenta.
  • El dataset "transfermarkt-datasets" que se mencionó como ejemplo de estructura de base de datos no incluye ninguna liga argentina. Sirve como inspiración de modelo de tablas (jugadores / partidos / transferencias / valuaciones), no como fuente de datos para este proyecto.
  • El punto que la charla anterior subestimó: no hacía falta pagar Wyscout para tener xG. Ya está gratis, partido a partido, en Sofascore — el ítem "predicción de resultados" y "análisis de rivales" del plan original son más baratos de arrancar de lo que parecía.

Lo que ninguna fuente externa te va a dar

Todo lo de arriba es sobre datos de terceros. Hay una categoría entera de datos que no tiene atajo: solo existe adentro del club. Es también, no es casualidad, la que más valor agrega — porque nadie más la tiene.

Socios
Altas, bajas, antigüedad, historial de pago, cuota, frecuencia de asistencia. Como Chacarita es una asociación civil (socios, no accionistas), este dato conecta directo con los ingresos recurrentes del club — más que en un club-empresa.
Plantel — cara interna
Sueldos reales, cláusulas de contrato, bonos por objetivos, duración efectiva. Ni Transfermarkt ni Sofascore tienen esto: publican estimaciones de mercado, no lo que el club paga.
Cuerpo médico y físico
GPS de entrenamiento, RPE, historial de lesiones, cargas semanales. Es el dato con mayor potencial de ROI (prevención de lesiones) y el que menos sustituto externo tiene.
Inferiores
Ningún proveedor de datos cubre juveniles de captación con el detalle necesario para modelar "¿quién llega a Primera?". Esa base solo la arma el propio club, partido a partido.
Entradas y comercial
Precio, sector, asistencia real, ventas de merchandising por talle/modelo. Dato transaccional puro del club — no existe en ninguna API de fútbol.

Encuadre legal, sin vueltas

Ninguna fuente gratuita está autorizada por escrito

Sofascore prohíbe copiar, reproducir o redistribuir su contenido sin permiso escrito. Transfermarkt prohíbe explícitamente el scraping automatizado y su uso para entrenar sistemas de IA. Ninguna de las dos persigue legalmente el uso personal de bajo volumen — es lo que hace toda la comunidad de analistas de fútbol amateur — pero la distinción importa para saber hasta dónde llevar esto:

  • Uso interno / prototipo / aprendizaje propio: riesgo bajo. Es exactamente lo que se hizo hoy: ~90 requests con una pausa de un segundo entre cada una, sin republicar nada.
  • Dashboard que ve el cuerpo técnico del club: riesgo bajo-medio. Recomendable avisarle al club que la fuente de fondo es no oficial, para que no quede como una promesa de continuidad garantizada.
  • Algo público, para hinchas, o que se vende: ahí ya no alcanza con esto. Ese escalón necesita una fuente con licencia — el plan pago de FootyStats o API-Football, o directamente un convenio con el club para que sea el club quien pague por datos con permiso.

Regla práctica: nunca paralelizar los requests a estas APIs, siempre con pausas, y tratar todo como un préstamo, no como una compra.

# la clave: curl_cffi imita la huella TLS de Chrome real
from curl_cffi import requests

def get(endpoint: str) -> dict:
    url = f"{BASE}{endpoint}"
    r = requests.get(url, headers=HEADERS, impersonate="chrome", timeout=15)
    time.sleep(1.0)  # cortesía: no martillar la API
    r.raise_for_status()
    return r.json()

Extender el mismo pipeline a Federal A y Metropolitana B/C/D (ya mapeadas, ver evidencia arriba) más valores de mercado de Transfermarkt. Primer modelo de similitud de jugadores acotado al presupuesto real de un club de Primera Nacional.

Fase 3 — 6 a 12 meses

Conversación con el club

Con el prototipo andando, es el momento de proponerle al club dos cosas en simultáneo: acceso a datos internos (socios, entradas, inferiores) y, si el proyecto va a tener uso oficial o público, migrar la capa de scouting a una fuente con licencia (FootyStats pago o un convenio directo).

Qué se puede romper

Fragilidad técnica

Sofascore ya bloquea la librería estándar de Python. Si en el futuro endurece el bloqueo del lado de curl_cffi también, el pipeline se corta hasta actualizar la técnica de impersonation. No tiene SLA — es normal que rompa sin aviso.

Dependencia de una sola fuente

Todo el prototipo hoy cuelga de Sofascore. Vale la pena, en la Fase 1, dejar Transfermarkt como fuente secundaria de contraste y no depender de un único proveedor no oficial para decisiones importantes.
